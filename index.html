Mauro’s logboek

Koppel je GitHub-repo

Het logboek bewaart alles als JSON-bestandjes in een privé-repo van jezelf. Eén keer instellen per telefoon.

  1. Maak op GitHub een privé repo, bv. baby-logboek-data.
  2. Maak een fine-grained personal access token (Settings → Developer settings) met enkel die repo en Contents: Read and write.
  3. Vul hieronder in. Je partner vult op haar telefoon dezelfde gegevens in.

Tik op een regel in het logboek om ze te bewerken. De volgende voeding begin je met de borst waar de vorige eindigde; dat staat bovenaan bij de aftelling. De gegevens staan in jullie eigen GitHub-repo en worden om de halve minuut ververst. Een echt alarm op een vergrendelde telefoon kan een webpagina niet zetten; zet daarvoor je wekker op de aangegeven tijd.
